# Graham Does Snacks — free PWA starter

This is a free installable website/app starter. It is not yet published online.

## Files
- `index.html` — app pages and styling
- `manifest.webmanifest` — installable app metadata
- `sw.js` — basic offline cache
- `icon-192.png`, `icon-512.png` — app icons

## Publish free with GitHub Pages
1. On your Windows PC, extract this ZIP.
2. Create or sign in to a GitHub account.
3. Create a new **public** repository named `graham-does-snacks`.
4. Upload the four app files (and this README if you like) to the repository's main/root folder.
5. Open repository **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**.
7. Choose **main** and **/(root)**, then Save.
8. Wait a few minutes. GitHub will show the public website address in Settings → Pages.

## Install on iPhone
Open the published website in Safari → Share → Add to Home Screen.

## Install on Android
Open the published website in Chrome → menu (⋮) → Install app / Add to Home screen.

## Notes
- GitHub Pages can host public static sites at no charge under its free offering. Check GitHub's current terms and limits.
- This PWA is not a native App Store / Google Play listing.
- The TikTok and Instagram buttons open the supplied public profile URLs.
- Review cards are placeholders; replace them with genuine reviews and links.
- Keep the repository public for the free GitHub Pages route.
